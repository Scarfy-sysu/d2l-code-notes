# 📘 动手学深度学习 · 代码笔记仓库 （持续更新中...）

本仓库基于李沐老师的《动手学深度学习（PyTorch版）》配套资料进行整理与实践记录，结合个人学习节奏对章节结构、代码注释和运行环境做了适配。

## 🚀 本仓库的特色

1. **章节结构调整**：根据个人理解对部分章节进行了重命名或拆分，`index` 文件中的部分超链接（如章节跳转）可能失效，请以目录实际文件为准。
2. **d2l 库兼容性优化**：
   - 第 8 章以前：官方 `d2l` 版本过新导致部分函数缺失，已将缺失函数补充在 `d2l包补充.ipynb` 中备用。
   - 第 8 章及之后：将 `d2l` 固定为 `0.17.6`、`jupyterlab` 固定为 `4.4.4`，无需修改源码即可运行示例。
3. **注释与讲解增强**：已学习的章节均添加了大量注释，特别是第 8 章之后的笔记更系统、逻辑更清晰，便于复习回顾。
4. **代码与讲解分离**：部分章节额外提供了纯代码版 `.ipynb`（仅包含实现与运行单元），方便快速验证效果。

## 📂 仓库结构

- `d2l-zh/`：章节对应的笔记与代码（含部分重命名或拆分文件）。
- `d2l包补充.ipynb`：早期章节运行所需的临时函数补充。
- `test.ipynb`：实验或临时测试用 notebook。
- `environment.yml`：完整的 Conda 环境依赖清单。

## 🛠️ 环境配置

### 方案一：使用 Conda（推荐）
```bash
conda env create -f environment.yml
conda activate d2l-zh
```
> 如需更新，可先删除旧环境或使用 `conda env update -f environment.yml --prune`。

### 方案二：快速安装关键依赖
```bash
pip install d2l==0.17.6 jupyterlab==4.4.4 torch==2.1.2+cu121 torchvision==0.16.2+cu121 torchaudio==2.1.2+cu121 -f https://download.pytorch.org/whl/torch_stable.html
```
> 若仅运行第 8 章以前的笔记，可根据提示从 `d2l包补充.ipynb` 中复制所需函数。

## 🧭 使用指南

1. 启动 JupyterLab：
   ```bash
   jupyter lab
   ```
2. 按章节打开对应的 `.ipynb` 文件，建议从第 8 章开始使用固定版本的环境运行。
3. 如遇到链接失效，请直接在 `d2l-zh/` 目录中按章节编号或名称查找文件。
